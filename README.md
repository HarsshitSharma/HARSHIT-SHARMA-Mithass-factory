🍰 Mithass Factory – Too Much Sweetness to Handle!

Mithass Factory is a modern and user-friendly bakery and sweets website developed as an academic project. The website showcases a wide variety of traditional Indian sweets, bakery products, and premium desserts with an attractive and responsive design.

This project focuses on delivering a rich visual experience using modern layouts, smooth animations, and an easy-to-navigate interface. It represents a digital presence for a sweets and bakery brand while highlighting full-stack web development skills.

---

📌 Project Features

- Attractive and responsive user interface  
- Organized product listing with descriptions  
- Smooth animations and modern layouts  
- Easy navigation across all devices  
- Clean and well-structured code  

---

🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- PHP  
- MySQL  

HTML, CSS, and JavaScript are used for the front-end design and interactivity, while PHP handles server-side logic and MySQL manages the database for storing product and user-related data.

---

📂 Project Purpose

This project was created for academic learning and practice. It demonstrates concepts of web designing, front-end development, and basic backend integration using PHP and MySQL.

---

🚀 How to Run the Project

1. Download or clone the repository  
2. Place the project folder inside the `htdocs` directory (for XAMPP)  
3. Start Apache and MySQL from XAMPP Control Panel  
4. Import the database file (if provided) into phpMyAdmin  
5. Open the browser and run:
   http://localhost/Mithass-Factory/
